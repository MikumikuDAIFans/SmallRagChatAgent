# Others

This section covers the auxiliary features in ArtiMaker, specifically accessing help resources and checking software information.

---

## 1. Help

Users can access the Help Center directly from the software interface to find documentation and support.

**Accessing Help:**
* Click the **Help** button (Question Mark icon `?`) located in the top menu bar.
* **Available Options:**
    * **Documentation:** Opens the user manual or documentation page.
    * **Tutorials:** Links to video tutorials.
    * **Feedback:** Allows users to send feedback or contact support.

> The image displays the top right corner of the software interface.
> * The mouse cursor is hovering over a **Question Mark (?)** icon.
> * A dropdown menu is visible, listing options such as "Documentation", "Tutorials", and "Feedback".

## 2. About

The "About" section provides information about the current software version and update options.

**Checking Version:**
1.  Click the **Settings** icon (Gear).
2.  Switch to the **About** tab.
3.  The interface displays the **Software Name** (ArtiMaker), **Version Number** (e.g., v1.0.0), and copyright information.
4.  **Check for Updates:** A button to check if a newer version of the software is available.
