## Device Tab

**Device Info**
* **Device Name:** laser
* **Connection Status:** DISCONNECTED
* **Communication Method:** USB / WIFI (optional)

**Connection Settings**
* **Port Selection:** Choose a port from the dropdown menu
* **Connect Button:** Click "Connect" to establish connection

**Movement Control**
* **Direction Control Buttons:**
    * X+ / X-
    * Y+ / Y-
    * Z+ / Z-

**Position Display**
* **Work Position:** X: 0, Y: 0, Z: 0
* **Machine Position:** X: 0, Y: 0, Z: 0

**Other Control Buttons**
* **Home:** Return to origin
* **Hold:** Pause operation
* **Unlock:** Unlock the device
* **ResetXY:** Set current XY as work origin
* **ResetZ:** Set current Z as work origin
* **Spindle:** Spindle On/Off (Click to turn on or off)
* **LaserOn:** Laser On/Off (Press and hold to turn on, release to turn off)
