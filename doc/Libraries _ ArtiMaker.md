# Libraries

ArtiMaker includes built-in Shape and Material libraries to speed up the design and simulation process.

---

## 1. Shape Library

The Shape Library provides a collection of pre-designed vector shapes, including basic geometric figures, icons, and decorative elements.

**Accessing the Library:**
Click the **Library** button (Book icon) in the left toolbar.

> **Image Summary:**
> The image shows the left vertical toolbar. The "Library" button, represented by an open book icon, is highlighted. It is located below the drawing tools (like Circle, Rectangle).

**Using Shapes:**
1.  **Browse:** The library window opens, displaying categories such as "Basic Shapes", "Animals", "Holidays", "Nature", etc.
2.  **Search:** Use the search bar at the top to find specific shapes (e.g., "Star").
3.  **Insert:** Click on a shape thumbnail, or drag and drop it onto the canvas.
4.  **Edit:** Once added, the shape acts like any other vector object. You can scale, rotate, or modify its path.

## 2. Material Library

The Material Library is used in the **3D Preview** mode to simulate the appearance of the finished workpiece. It includes preset textures like woods, metals, and plastics.

**Changing Material:**
1.  Enter the **3D Preview** interface.
2.  In the "Display Options" or "Parameters" panel on the right, find the **Material** dropdown menu.
3.  Select a preset material (e.g., "Wheat", "Dark Oak", "MDF").

> **Image Summary:**

### Custom Materials

Users can add their own material textures for more accurate simulation.

**Steps to Add Custom Material:**
1.  Open the Material dropdown and scroll to the bottom.
2.  Click **+ Add Custom Material**.
3.  **Upload Texture:** Select a generic image file (`.jpg` or `.png`) representing the material surface.
4.  **Set Size:** Define the physical width and height that the texture image represents (to ensure correct scaling).
5.  **Save:** The new material will appear in the list.
