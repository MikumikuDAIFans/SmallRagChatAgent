# Tool and Material Reference Guide

## 📐 1. Tool Selection Guide

### 1.1 Tool Type Overview

| Tool Type | Application Scenarios | Advantages | Disadvantages |
|-----------|----------------------|------------|---------------|
| **Flat End Mill** | Pocket clearing, surface machining | Flat bottom, high efficiency | Corners not sharp enough |
| **V-Bit Engraving Tool** | Text engraving, 3D relief | Sharp edges, clear details | Easy to break, requires careful operation |
| **Ball End Mill** | Detail engraving, curved surface machining | Smooth surface, suitable for complex curves | Low efficiency, requires multiple passes |

### 1.2 Tool Selection by Machining Type

#### Outline Cutting
- **Tool**: Flat End Mill
- **Diameter**: 3.175-6mm (depending on material thickness)
- **Flutes**: 1-2 flutes

#### Pocket Clearing
- **Tool**: Flat End Mill
- **Diameter**: 3.175-6mm
- **Flutes**: 2-3 flutes (use more flutes for hard materials)

#### 3D Relief
- **Tool**: Flat End Mill + V-Bit
- **Diameter**: 1.5-6mm (depending on detail level)
- **Recommendation**: Use larger tools for large areas, smaller tools for details
